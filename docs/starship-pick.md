# `starship-pick`

An interactive Starship prompt theme switcher for Linux and macOS, built for [`qol-scripts`](../README.md).

`starship-pick` allows you to preview, select, and switch between [Starship](https://starship.rs/) prompt themes stored in a central themes repository using [`fzf`](https://github.com/junegunn/fzf) or direct command-line arguments.

## Overview

When customizing Starship prompts across multiple setups or color palettes, updating your shell configuration file manually each time is cumbersome.

`starship-pick` streamlines theme management:
- **Centralized Target**: Copies your chosen theme `.toml` file to a dedicated destination (`<themes-dir>/custom/starship.toml`).
- **Interactive Fuzzy Finding**: Launches `fzf` with a clean interface to quickly choose among available `.toml` themes.
- **Smart Direct Matching**: Accepts full names, names without `.toml`, names omitting the `starship_` prefix, or unique substrings.
- **Immediate Effect**: Prompts pick up the new configuration without requiring manual shell file edits once `$STARSHIP_CONFIG` is set.

## Prerequisites

Ensure the following dependencies are installed on your system:

1. **[Starship](https://starship.rs/)**: The cross-shell prompt (`curl -sS https://starship.rs/install.sh | sh` or your package manager).
2. **[fzf](https://github.com/junegunn/fzf)**: Command-line fuzzy finder (required for interactive selection).
3. **Themes Collection**: A directory containing Starship `.toml` configurations (defaults to `~/dev/starship-themes`).
4. **[Nerd Font](https://www.nerdfonts.com/)** *(Recommended)*: A patched font such as FiraCode Nerd Font to properly display prompt glyphs and symbols.

## Installation

`starship-pick` is an optional module in the [`qol-scripts`](../README.md) suite.

### 1. Install via the `qol` CLI

Use the built-in `qol` manager to create a symlink in your `bin/` directory:

```bash
qol install starship-pick
```

To verify the installation:

```bash
which starship-pick
```

### 2. Manual Symlink (Alternative)

If you are not using the `qol` helper, create a symlink manually:

```bash
ln -s "$QOL_SCRIPTS_PATH/src/starship-pick" "$QOL_SCRIPTS_PATH/bin/starship-pick"
```

Ensure `$QOL_SCRIPTS_PATH/bin` is in your shell's `$PATH`.

### Uninstallation

To remove the script:

```bash
qol uninstall starship-pick
```

## Shell Configuration

To enable Starship to consume the active theme selected by `starship-pick`, point `STARSHIP_CONFIG` to the generated `custom/starship.toml` file in your shell configuration (`~/.bashrc`, `~/.zshrc`, etc.):

```bash
# Set path to the active Starship configuration generated by starship-pick
export STARSHIP_CONFIG="$HOME/dev/starship-themes/custom/starship.toml"

# Initialize Starship for your shell (bash, zsh, fish, etc.)
eval "$(starship init bash)"
```

> [!TIP]
> If your themes collection lives in a non-default location (not `~/dev/starship-themes`), export `STARSHIP_THEMES_PATH` as well:
> ```bash
> export STARSHIP_THEMES_PATH="$HOME/my-starship-themes"
> export STARSHIP_CONFIG="$STARSHIP_THEMES_PATH/custom/starship.toml"
> ```

## Usage

```text
Usage: starship-pick [options] [theme-name]
```

### Interactive Mode (fzf)

Running `starship-pick` without arguments opens an interactive `fzf` picker:

```bash
starship-pick
```

- Use the **Up / Down** arrow keys to browse themes.
- Press **Enter** to apply the selected theme.
- Press **Esc** or **Ctrl+C** to cancel without making changes.

### Direct Selection

You can specify the theme directly as an argument without entering interactive mode. `starship-pick` supports multiple matching styles:

1. **Exact filename:**
   ```bash
   starship-pick starship_green.toml
   ```

2. **Omit `.toml` extension:**
   ```bash
   starship-pick starship_cyan
   ```

3. **Omit `starship_` prefix (short name):**
   ```bash
   starship-pick midnight
   starship-pick orange
   ```

4. **Fuzzy substring match:**
   ```bash
   starship-pick mid    # Resolves to starship_midnight.toml
   ```

> [!NOTE]
> If a substring matches more than one theme, `starship-pick` displays all matching themes and prompts you to specify a more specific name.

### List Themes

To view all available themes in your themes directory without launching interactive selection:

```bash
starship-pick --list
# or
starship-pick -l
```

Example output:
```text
===== Available Starship Themes =====
  • starship_blue.toml
  • starship_cyan.toml
  • starship_green.toml
  • starship_midnight.toml
  • starship_mint.toml
  • starship_orange.toml
  • starship_pink.toml
  • starship_purple.toml
  • starship_red.toml
  • starship_white.toml
```

### Custom Themes Directory

To use a themes repository outside of `~/dev/starship-themes`:

```bash
starship-pick --dir ~/path/to/themes
starship-pick -d ~/path/to/themes mint
```

## Options Reference

| Option | Flag | Description |
|---|---|---|
| `--dir <path>` | `-d <path>` | Specify a custom Starship themes directory (default: `~/dev/starship-themes` or `$STARSHIP_THEMES_PATH`) |
| `--list` | `-l` | List all available `.toml` themes without starting the interactive selector |
| `--help` | `-h` | Display usage and option summary |
| `[theme-name]` | *(positional)* | Name, prefix, or substring of the theme to apply directly |

---

## Environment Variables

| Variable | Description | Default Value |
|---|---|---|
| `STARSHIP_THEMES_PATH` | Path to the directory where Starship theme `.toml` files reside. | `~/dev/starship-themes` |
| `STARSHIP_CONFIG` | Path to the active Starship configuration file. Monitored by `starship-pick` to verify your environment is configured correctly. | None *(Starship defaults to `~/.config/starship.toml`)* |
| `QOL_SCRIPTS_PATH` | Root path to the `qol-scripts` repository (used to source `qol-preamble`). | Auto-detected / None |

## How It Works

1. **Environment Setup & Verification**:
   Loads helper colors and verifies dependencies (like `fzf`) via `tools/qol-preamble`.
2. **Directory & File Discovery**:
   Recursively scans `$THEMES_DIR` for all `*.toml` files, excluding git internals (`.git/*`) and the target destination file (`custom/starship.toml`).
3. **Selection / Resolution**:
   - If a theme name argument is supplied, it attempts exact match, extension match, prefix match (`starship_<name>.toml`), and single substring matching.
   - If no argument is supplied, it invokes `fzf` in reverse layout with rounded borders.
4. **Application**:
   Ensures the `<themes-dir>/custom/` directory exists and copies the selected `.toml` file to `<themes-dir>/custom/starship.toml`.
5. **Configuration Check**:
   If `$STARSHIP_CONFIG` is set in your current shell but does not match the target `custom/starship.toml` path, the script outputs a friendly notification reminding you to update your shell configuration.

## Troubleshooting

### "Error: Themes directory not found"
- Verify that `~/dev/starship-themes` exists.
- If your themes are in another directory, export `STARSHIP_THEMES_PATH="<path>"` in your shell RC or pass `--dir <path>`.

### "Error: fzf could not be found"
- Install `fzf` via your system package manager (e.g., `pacman -S fzf`, `apt install fzf`, or `brew install fzf`).

### "Notice: Your current environment has STARSHIP_CONFIG=..."
- This message appears when `$STARSHIP_CONFIG` is set but points somewhere other than `<themes-dir>/custom/starship.toml`.
- Update your `~/.bashrc` or `~/.zshrc`:
  ```bash
  export STARSHIP_CONFIG="$HOME/dev/starship-themes/custom/starship.toml"
  ```
  Then reload your shell (`source ~/.bashrc` or open a new terminal window).
